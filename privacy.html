Privacy Policy - NGLH eBay Sync Tool

This is a private internal tool built for a single eBay seller (NGLH Trading) to manage their own eBay listings and sales reporting. It is not a public application and is not offered to other eBay users.

What this tool accesses

Using eBay's APIs, this tool reads and updates data belonging solely to the NGLH Trading eBay seller account, including:

  • Listing quantities (to keep stock levels in sync)
  • Order and sales data (to generate sales reports)
  • Listing traffic/view statistics (to show per-listing view counts in sales reports)

How the data is used

Data is used only to power this tool's own features: syncing stock levels and generating email sales reports for the account owner. It is not shared with, or sold to, any third party.

Where data is stored

Data is stored using Netlify's hosting infrastructure, solely for this tool's own operation, and is not accessible to anyone other than the account owner.

Contact

Questions about this tool can be directed to the account owner via the email address associated with this eBay Developer account.
